# Python Laboratory Work

An organised archive of Python laboratory exercises and programming practice completed during undergraduate coursework.

## Contents

Exercises are grouped by the existing directory structure:

- `ex1/` through `ex5/`
- `EX6/`, `EX7/`, and `EX8/`

Folder names are preserved as they currently exist in the repository.

## Running an exercise

Install Python 3, open a terminal in the repository, and run the required script:

```bash
python path/to/program.py
```

On systems where Python 3 uses the `python3` command:

```bash
python3 path/to/program.py
```

Replace the example path with the actual file you want to run. Individual exercises may have their own input requirements.

## Purpose

This repository serves as an **academic archive and learning reference** for Python fundamentals and laboratory work. It is kept separate from portfolio applications and is not intended to represent a production software project.
