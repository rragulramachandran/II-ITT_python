# Python Laboratory Coursework

An organized archive of Python laboratory exercises, programming assignments, and object-oriented design problems completed during undergraduate coursework.

## Laboratory Exercise Breakdown

| Exercise | Topic | Files | Description |
|----------|-------|-------|-------------|
| **ex1** | Python Fundamentals | `basics.py` | Variables, primitive data types, input/output formatting, and arithmetic operators. |
| **ex2** | Object-Oriented Records | `employee_management.py` | Employee record management using classes, instance attributes, salary calculations, and formatted report printing. |
| **ex3** | Regular Expressions | `gmail_validator.py` | String validation using Python's `re` module to verify standard Gmail address syntax and format compliance. |
| **ex4** | String Processing | `word_analyzer.py` | Text analytics, word tokenization, character frequency mapping, and string manipulation metrics. |
| **ex5** | Set Operations | `setopr.py` | Discrete mathematical set operations: Union ($A \cup B$), Intersection ($A \cap B$), Difference ($A \setminus B$), and Symmetric Difference ($A \Delta B$). |
| **EX6** | Arithmetic & Functional Ops | `aropr.py` | Mathematical utility functions, modular operations, and functional programming routines. |
| **EX7** | Combinatorics & Itertools | `colors.py`, `comb.py`, `count.py`, `cycle.py`, `islice.py`, `perm.py`, `perm2.py` | Comprehensive exploration of the `itertools` library: combinations (`combinations`), permutations (`permutations`), infinite counters (`count`), repeating cycles (`cycle`), and slice iterators (`islice`). |
| **EX8** | Object-Oriented Programming (OOP) | `p1.py` – `p5.py` | Five progressive OOP design exercises: class definitions (`Car`), constructors & state (`Book`, `Rectangle`), default parameters (`Fan`), and inheritance/polymorphism (`Animal` $\rightarrow$ `Cat`). |

## Running the Programs

All scripts require **Python 3.x**. Run any exercise directly from the terminal:

```bash
# Exercise 1: Basics
python ex1/basics.py

# Exercise 3: Gmail Validator
python ex3/gmail_validator.py

# Exercise 7: Permutations and Combinations
python EX7/comb.py
python EX7/perm.py

# Exercise 8: OOP Demonstrations
python EX8/p3.py
python EX8/p5.py
```

## Purpose

This repository is maintained as an **academic record and learning reference** covering core Python programming, regular expressions, functional combinatorics, and object-oriented design.
